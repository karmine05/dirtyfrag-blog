**Dhruv Majumdar** — Security operations engineer working on endpoint management at scale.
Based in Toronto, Canada. Currently at **Fleet Device Management**.

I help CIOs, CISOs, and CTOs turn fragmented endpoint data, shadow IT, and vulnerability noise into something a small team can actually act on. These notes are about how I run security ops day to day — the tools, the patterns, and the things that didn't work.

Most of what I write touches **Fleet**, **osquery**, **Linux internals**, and the gap between "the vendor said this fixes it" and "the host actually fixed it."

## What I work on

- **Endpoint observability at scale** — Fleet, osquery, host-based detection, fleet-as-code via GitOps.
- **Threat hunting and detection engineering** — turning raw host artifacts into reproducible queries and live policies.
- **Pre-CVE response** — handling public exploits before NVD catches up; artifact-based scoping instead of catalog lookups.
- **AI for security ops** — natural-language interfaces to endpoint data via MCP, with the SQL still visible to the analyst.
- **Supply-chain incident response** — npm/pypi/go module worms, credential harvesting, and what Fleet's tables actually cover.
